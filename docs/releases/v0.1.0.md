# v0.1.0 — 2026-10-29

First public release. A folder structure for working with AI agents on long-running
projects, organised by how much each file can be trusted, and installed with one command.

```bash
curl -fsSL https://raw.githubusercontent.com/aidilikbar/llm-wiki-workspace/main/install.sh | bash
```

## Shipped

- **Four zones by mutability** — `context/` stable, `state/` current, `record/`
  append-only, `work/` untrusted — plus `system/` for rules, roles, workflows and
  templates. Every markdown file carries front matter, and a pre-commit hook rejects any
  that does not.
- **Interactive installer.** Run it in a folder and it asks: workspace or `.handoff/`,
  where, core or full, Obsidian, git. Every question has a flag; `--yes` never asks. Works
  through `curl | bash`.
- **One file per item** for every collection — requirements (`R-NNN`), backlog and
  icebox (`T-NNN`), sprints (`S-NN`), decisions, logbook, research, prompts — with a
  template for each and the naming rules in `system/RULES.md` §9.
- **Planner–executor workflow.** `install.sh --handoff` sets up a `.handoff/` exchange in
  a code repo so a planning agent and an executing agent trade tasks and results through
  files instead of copy-paste.
- **Research zone** — one question per file in `work/research/`, ending in options, never
  a verdict, until a human promotes it.
- **Obsidian support** behind `--obsidian`: templates folder, properties, graph coloured
  by zone. Also as a ready-to-open vault zip attached to this release.
- **`--git`** initialises the repository and switches the front-matter check on.

## Known issues

- `npx llm-wiki-workspace` is documented but the package is not yet on npm. Use the curl
  route.
- On Windows the Node installer cannot open the terminal for questions; pass flags.
- `system/workflows/documentation-workflow.md` and `onboarding.md` are still stubs.

## Migration required

None — first release.

## Rollback

Delete the installed folders, or for a `.handoff/` install: remove `.handoff/`, the block
between the `llm-wiki-workspace:handoff-protocol` markers in `AGENTS.md` (and
`CLAUDE.md` if it was a file), the `CLAUDE.md` link if the installer created it, and the
`.handoff/` line in `.gitignore`.
